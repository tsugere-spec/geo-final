# 新地理総合 期末テスト対策

帝国書院『新地理総合』に対応する、提供ワークをもとにしたオリジナル問題集です。全110問を収録しています。

## 学習方法

1. 全範囲または5つの地域から出題範囲を選びます。
2. 一問一答または4択を選びます。一問一答は自己採点です。4択は全110問に問題専用の誤答があり、採点後に正答の根拠と選択肢の違いを確認できます。
3. 「全問正解するまで繰り返す」を選ぶと、その周に間違えた問題だけが次の周に出ます。「苦手だけ復習」では、選んだ範囲のうち直近で誤答した問題を出題します。
4. 同じブラウザでページを再び開き、「前回の続きから」を押すと中断した画面から再開します。

習得済み・苦手は各問題の直近の採点結果で集計し、累計正答率には再挑戦を含む全採点を反映します。学習履歴はブラウザの localStorage にのみ保存します。ログイン、個人情報の入力、API、アプリ用サーバーは不要です。

基礎は重要語句を中心に60問、標準は全110問、応用は資料・因果関係・紛らわしい語句を中心に48問を収録しています。初期設定は標準です。「苦手だけ復習」では、難易度をまたいで選択地域の誤答を出題します。

## テスト

Node.js で `node tests/quiz.test.cjs` を実行すると、全110問の選択肢、難易度、採点、再出題、履歴の復元を確認できます。

## GitHub Pages での公開

1. リポジトリの公開先ブランチに `index.html`、`questions.js`、`choices.js`、`app.js`、`mobile.css`、`.nojekyll` を配置します。
2. リポジトリの **Settings → Pages** で **Deploy from a branch** を選び、公開先ブランチの **/ (root)** を保存します。
3. Pages のデプロイ成功後、同じ画面に表示される公開URLを開き、問題表示と再開機能を確認します。このURLをLINEなどで共有できます。

## ファイル構成

- `questions.js` に添付HTMLの問題・解答・解説を収録しています。教材の掲載時点を前提とするデータを含みます。
- `choices.js` に設問別の誤答と比較解説、複数の解釈が可能な設問の4択用文面を収録しています。
- `app.js` が出題、採点、周回、進捗、保存と復元を処理します。
- `index.html` と `mobile.css` が画面を構成します。
